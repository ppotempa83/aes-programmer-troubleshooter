Operating notes
Safe reset / monitor notes
- Type a through j as lower-case commands.
- When entering hexadecimal values, use upper-case A-F.
- Set Tera Term backspace handling to destructive if available.
- Press Enter after a requested value.
- Commands a, b, and c toggle monitoring; turn them off when finished.
- Command j resets RAM/defaults except the ID number and Cipher; answer its Y/N prompt carefully.
- If a monitor mode is left on, reset the unit after work is complete.
