SUPERIOR AES PROGRAMMER - INSTALL THIS CERTIFICATE FIRST
========================================================

This release is signed with an internal Superior Fire & Security code-signing
certificate. The private signing key is not included in this package.

Easiest installation
--------------------
1. Extract the entire release ZIP to a local folder.
2. Edit credentials.local.txt if this deployment needs a Geoapify key.
3. Run {INSTALLER_FILE} as an administrator.
4. Windows may show Unknown Publisher on this first launch because the computer
   has not trusted this internal certificate yet. Confirm the setup filename and
   the certificate thumbprint below before approving it.
5. Leave the default Certificate Trust and Deployment Credentials choices
   selected. Setup imports both quietly, installs the verified FTDI VCP driver
   quietly, and then installs the app.

Manual certificate-first alternative
------------------------------------
1. Extract the entire release ZIP to a local folder.
2. Right-click {CERTIFICATE_FILE}, select Install Certificate, and approve the
   Windows administrator prompt.
3. Select Local Machine.
4. Select "Place all certificates in the following store", browse to
   "Trusted Root Certification Authorities", and finish the wizard.
5. Run the certificate import a second time and choose "Trusted Publishers".
6. Right-click the setup EXE, open Properties > Digital Signatures, and confirm
   that Windows reports the digital signature as OK and shows this thumbprint:
   {CERTIFICATE_THUMBPRINT}
7. Run {INSTALLER_FILE} as an administrator. Setup recognizes an already
   installed certificate.

Setup order
-----------
The setup program first extracts the verified, unmodified FTDI CDM 2.12.36.20
payload and runs its signed x64 DPInst package quietly. Superior AES Programmer
is installed only after the driver package reports success.

Security notes
--------------
- This .cer file contains only a PUBLIC certificate. It cannot sign software.
- Never accept a .pfx, .p12, private-key file, or certificate password in a
  technician release package.
- A self-signed certificate establishes trust only on computers where your
  organization deliberately installs it. It does not create public SmartScreen
  reputation.
- Remove an obsolete internal certificate from Trusted Root Certification
  Authorities and Trusted Publishers after Superior Fire & Security announces
  a certificate rotation or revocation.
